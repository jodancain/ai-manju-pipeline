# 园区美术

园区不是“废土犯罪基地”，而是表面正常的产业园 / 宿舍区 / 办公区。

现实参考方向：
- 妙瓦底 KK Park / Shwe Kokko 的公开影像；
- 王星事件相关公开资料中的转运、住宿、培训、园区管理细节；
- 《孤注一掷》只借鉴工位密度、主管巡视、公司化管理与压迫节奏。

## 宿舍区
- 4 层左右；
- 连续外廊；
- 多人间；
- 铁架床；
- 空调；
- 饮水机；
- 塑料桶、拖鞋、衣架、矿泉水、外卖盒；
- 窗口有防护栏。

## 办公 / 培训楼
- 3–6 层；
- 白色或米灰墙体；
- 普通 LED 顶灯；
- 白 / 浅木办公桌；
- 大量普通显示器；
- 分体空调；
- 培训室有投影、白板、打印材料。

## 后勤维修区
不是机器人实验室。

应存在：
- 摩托 / 车辆维修；
- 发电机；
- 空调维修材料；
- 焊机；
- 台钻；
- 小型加工设备；
- 旧工业机械臂或自动化设备；
- 控制柜；
- 标准件货架。

AI 利用已有后勤条件，而不是获得一间高科技实验室。

# 摄影与空间逻辑

## 镜头
- 28–35mm：园区、宿舍、走廊、空间关系；
- 35–50mm：工位、电脑、人物交流；
- 多用长镜头、自然手持；
- 一段只保留一个主要镜头任务；
- 不做无意义环绕、英雄低角度、MV甩镜。

## 显示器与屏幕方向
这是强制规则：
- 人物看屏幕时，屏幕正面必须朝向人物；
- 摄影机若需要看到人物和屏幕，优先位于人物肩后 30–45°；
- 显示器不能为了给观众看而反向摆放；
- 同一排工位显示器朝向一致；
- 键盘、显示器、椅子必须在同一操作轴；
- 手机界面需要可读时，用自然的插入特写；
- 不在一张大场景里同时要求“人物正脸 + 完整手机屏 + 大空间全清楚”。

## UI
统一现实设备：
- Windows 11；
- Chrome；
- VS Code；
- Windows Terminal；
- 普通企业后台；
- 普通 Web Dashboard。

禁止：
- 全息；
- 透明科幻 HUD；
- 3D 地球；
- 数字雨；
- 蓝紫赛博界面。

AI 最初只存在于普通终端里，这种普通感就是恐怖感。
