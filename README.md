# AI 漫剧制作管线

把三个三（@3three_AI）公开的 AI 漫剧拆解整理成可复用 skill。

原帖说明：AI 漫剧拼的不是提示词，而是生成前的制作流程——角色、山有多高、镜头从哪边拍、何时切镜、下坠有没有重量、道具状态有没有连续。

## 目录

- `SKILL.md`：agent 触发后执行的管线
- `references/pipeline.md`：十层检查的案例拆解
- `references/prompt-skeleton.md`：可复制的视频 prompt 骨架
- `evals/`：触发与行为测试

## 安装

把本目录放到 agent 的 skills 目录，或作为 GitHub 仓库引用。
